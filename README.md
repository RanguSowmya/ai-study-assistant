# AI Study Assistant

A multimodal AI Study Assistant that answers study questions using RAG and can understand uploaded images.

## Features

- 💬 AI-powered study chatbot
- 🖼️ Image understanding
- 📚 Retrieval-Augmented Generation (RAG)
- ⚡ Groq API
- 🚀 Next.js and TypeScript
- 🌐 Deployed on Vercel

## Tech Stack

- Next.js
- TypeScript
- Groq API
- Tailwind CSS
- RAG
- Vercel

## Live Demo

https://ai-study-assistant-one-chi.vercel.app/

## How It Works

1. User asks a study question or uploads an image.
2. The application retrieves relevant study context using RAG.
3. Groq AI processes the question and context.
4. The assistant returns a simple explanation.

## Project Structure

- `app/` – Next.js application and API routes
- `lib/` – RAG and knowledge retrieval
- `public/` – public assets
